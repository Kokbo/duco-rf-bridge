# Merge these lines into /ext/subghz/assets/setting_user on the Flipper SD card

# Frequency = 868.29 (or the one listed below).
#
# Derived from the register table in arnemauer/Duco-RF-protocol, with changes
# for Flipper's asynchronous RAW mode (it timestamps the demodulated bit stream
# on GDO0 instead of using the CC1101 packet engine):
#   IOCFG0   0x07 -> 0x0D  (serial data out on GDO0)
#   PKTCTRL0 0x05 -> 0x32  (asynchronous serial mode, no CRC/length handling)
#   MDMCFG2  0x13 -> 0x10  (GFSK, no sync-word detection in async mode)
#   MCSM0    0x08 -> 0x18  (auto-calibrate on idle->RX, needed by Flipper)
#   MCSM1    0x27 -> 0x30  (return to idle after RX/TX)
# Everything else (frequency, bandwidth, deviation, AGC, FREND, FSCAL) is
# unchanged. IOCFG2 (address 0x00) is left out because 00 marks the end of the
# register list. PATABLE is C5 as in the Duco config.
